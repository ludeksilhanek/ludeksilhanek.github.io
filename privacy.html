Žán briefing – zásady ochrany soukromí

Platné od 23. 10. 2026. Žán briefing je osobní nástroj, který používá jen jeho autor, Luděk Šilhánek, s vlastním Google účtem.

Jaká data nástroj čte

S oprávněním gmail.readonly (jen čtení) čte z autorova Gmailu výhradně zprávy se štítkem Newslettery/AI – informační newslettery od schválených odesílatelů. Nečte jiné zprávy, kontakty ani jiné služby Google. Nic neposílá, nemaže ani neupravuje.

K čemu data slouží

Z newsletterů se vytvoří několik krátkých bodů do soukromého ranního přehledu autora. Text newsletterů se ke shrnutí předá jazykovému modelu (GitHub Models). Data se nepoužívají k reklamě, nikomu se neprodávají ani nepředávají a nepoužívají se k trénování modelů.

Uložení a zabezpečení

Celé texty e-mailů se neukládají. Ukládá se jen krátký souhrn v soukromém repozitáři autora na GitHubu. Přístupové klíče jsou uložené jako šifrované tajné hodnoty (GitHub Actions Secrets), nikdy v kódu.

Zrušení přístupu

Přístup lze kdykoli odvolat v nastavení Google účtu: myaccount.google.com/connections → Žán briefing → Odebrat přístup.

Soulad s pravidly Google

Použití a předávání informací získaných z Google API se řídí zásadami Google API Services User Data Policy, včetně požadavků Limited Use.

English summary

Žán briefing is a personal tool used only by its author with his own Google account. With the read-only scope gmail.readonly it reads only messages labelled Newslettery/AI in the author's Gmail and turns them into a few short points for his private daily briefing. Newsletter text is sent to a language model (GitHub Models) for summarisation. No data is sold, shared, used for advertising or for model training. Full email texts are not stored; only a short summary is kept in the author's private GitHub repository; credentials are stored as encrypted GitHub Actions secrets. Access can be revoked at any time at myaccount.google.com/connections. The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
